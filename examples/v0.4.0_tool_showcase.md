# v0.4.0 Tool Showcase

Representative live outputs from the individual genesis-bio-mcp tools, captured
against the real upstream APIs. These complement the `*_report.{json,md}` files
in this directory, which show the orchestrated `prioritize_target` output.

Highlights the v0.4.0 work specifically: AlphaFold confidence, Foldseek
structural search (M4), Open Targets tractability, Reactome FDR, STRING evidence
channels, GTEx tissue-specificity, the honest DepMap approximation caveat, and
the HPA target-accessibility classification.

> Outputs are point-in-time snapshots — live database values drift over time.

## `get_structural_homologs` — Foldseek structural search (M4, v0.4.0)

Finds proteins with a similar 3D fold, even when sequence has diverged.

Query: `get_structural_homologs(gene_symbol="BRAF", max_hits=10)`

```
## Structural homologs (Foldseek): BRAF
**Query:** AlphaFold model of `P15056` | **Database:** afdb-swissprot | **10 hits**

| Target | Description | E-value | Bit score | Prob | % id |
|---|---|---:|---:|---:|---:|
| `AF-P34908-2-F1-model_v6` | Serine/threonine-protein kinase B-raf | 0.0e+00 | 2834 | 1.00 | 93 |
| `AF-P28028-F1-model_v6` | Serine/threonine-protein kinase B-raf | 0.0e+00 | 2813 | 1.00 | 92 |
| `AF-A7E3S4-2-F1-model_v6` | RAF proto-oncogene serine/threonine-prot | 6.0e-73 | 1931 | 1.00 | 55 |
| `AF-P05625-F1-model_v6` | RAF proto-oncogene serine/threonine-prot | 1.6e-72 | 1925 | 1.00 | 56 |
| `AF-P04049-F1-model_v6` | RAF proto-oncogene serine/threonine-prot | 4.2e-72 | 1870 | 1.00 | 56 |
```

The query's own model is excluded; the top hits are B-raf orthologs followed by
the rest of the RAF kinase family (RAF1/CRAF `P04049`, ARAF) — the correct fold
family. Works on non-globular folds too — e.g. `GLP1R` (a 7TM GPCR) returns GLP1R
orthologs then the glucagon receptor.

## `get_protein_interactome` — STRING dominant evidence channel + configurable threshold (v0.4.0)

Query: `get_protein_interactome(gene_symbol="BRAF", required_score=900, limit=8)`

```
## Protein Interactome: BRAF
**8 interaction partners** (STRING confidence ≥ 0.90)

| Partner | Score | Top evidence | Channels |
|---|---|---|---|
| **KRAS** (KRAS) | 0.999 | textmining (0.97) | experiments, database, textmining |
| **NRAS** (NRAS) | 0.999 | textmining (0.97) | experiments, database, textmining |
| **HRAS** (HRAS) | 0.999 | experiments (1.00) | experiments, database, textmining |
| **MAP2K1** (MAP2K1) | 0.999 | experiments (1.00) | experiments, database, textmining |
| **RAF1** (RAF1) | 0.999 | textmining (0.98) | experiments, database, textmining |
| **YWHAZ** (YWHAZ) | 0.999 | experiments (1.00) | experiments, database, textmining |
```

Same combined score, different evidence quality: MAP2K1/HRAS/YWHAZ are
experiment-backed, while KRAS/NRAS lean on text-mining — a selectivity-relevant
distinction. The threshold (`required_score`) and `limit` are tunable per call.
